# Service Requirements

## Functional Requirements

- Users can sign up, log in, and view their profile.
- Users can create and manage product posts.
- Users can create conversations linked to product posts.
- Users can add chat messages one by one, in bulk, or from a transcript.
- Users can run analysis on a conversation.
- Users can view final condition summaries, alerts, and condition history.
- Users can generate and download PDF evidence packages.

## Non-Functional Requirements

- Backend only for the first milestone.
- JWT-secured APIs except auth, health, and Swagger endpoints.
- No hardcoded secrets.
- Rule-based analysis must work without external API keys.
- Clear package structure for portfolio presentation.
- Tests must cover core analysis logic.

## Out Of Scope For MVP

- Frontend implementation.
- Real marketplace crawling or scraping.
- Sending real private chat data to external AI providers.
- Legal judgment automation.
