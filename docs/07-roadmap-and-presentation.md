# Roadmap And Presentation

- Spring Boot backend setup
- JWT auth
- Product posts
- Conversations and messages
- Rule-based analysis
- PDF evidence generation
- Swagger and documentation

## Milestone 2

- Frontend integration
- Better analysis review UI

- Optional Gemini integration
- Provider abstraction hardening
- Structured LLM output validation
- Audit logs and export history

## Presentation Angle

DealGuard is not another marketplace. It is a transaction condition verification and dispute preparation backend. The portfolio value is in the domain modeling, security, analysis pipeline, evidence generation, and extensible AI architecture.
